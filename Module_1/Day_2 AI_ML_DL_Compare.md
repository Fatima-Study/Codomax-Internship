## 🤖 What is Artificial Intelligence?

**Artificial Intelligence (AI)** is the broader concept of creating machines and computer systems that can perform tasks requiring human-like intelligence.

AI can involve:

- Reasoning
- Problem-solving
- Decision-making
- Language understanding
- Image recognition
- Learning

### Example

A chatbot that understands user questions and provides appropriate responses is an example of an AI application.

---

## 📊 What is Machine Learning?

**Machine Learning (ML)** is a subset of Artificial Intelligence. It allows computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

### Example

An email spam filter can learn from previous emails and classify new messages as **spam** or **not spam**.

### Common ML Applications

- Spam detection
- Fraud detection
- Recommendation systems
- Predictive analysis
- Customer classification

---

## 🧠 What is Deep Learning?

**Deep Learning (DL)** is a subset of Machine Learning that uses **artificial neural networks with multiple layers** to learn complex patterns from large amounts of data.

Deep Learning is especially useful for tasks involving:

- Images
- Speech
- Video
- Natural language
- Complex pattern recognition

### Example

A face recognition system can use Deep Learning to identify patterns in facial images.

---

## ⚖️ AI vs ML vs Deep Learning

AI, Machine Learning, and Deep Learning are closely related technologies, but they differ in their scope and approach.

| Feature | Artificial Intelligence (AI) | Machine Learning (ML) | Deep Learning (DL) |
|---|---|---|---|
| Definition | Broad field of intelligent systems | Subset of AI that learns from data | Subset of ML using neural networks |
| Main Focus | Intelligent behavior | Learning from data | Learning complex patterns |
| Data Requirement | May vary | Requires training data | Usually requires large datasets |
| Technique | Rules, algorithms, ML, etc. | Learning algorithms | Multi-layer neural networks |
| Example | Intelligent chatbot | Spam detection | Face recognition |

## 🔍 Key Differences

### 🤖 Artificial Intelligence

AI is the broadest concept. It focuses on creating systems that can perform tasks that normally require human intelligence.

### 📊 Machine Learning

ML is a subset of AI. It enables computers to learn patterns from data and make predictions or decisions.

### 🧠 Deep Learning

Deep Learning is a subset of ML. It uses multi-layer neural networks to automatically learn complex patterns from large amounts of data.

### In Simple Terms

> **AI** → Makes machines intelligent  
> **ML** → Enables machines to learn from data  
> **DL** → Uses deep neural networks to learn complex patterns
