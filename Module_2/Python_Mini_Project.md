## 📌 Overview

The **Student Grade Calculator** is a beginner-friendly Python mini project developed as part of the **Codomax Digital Solutions Internship**.

The project allows users to enter a student's name and marks for different subjects. It then calculates the total marks, percentage, and final grade automatically.

This project demonstrates the practical use of basic Python programming concepts such as **variables, user input, arithmetic operations, conditional statements, and output formatting**.

## 🎯 Objective

The main objective of this project is to apply basic Python programming knowledge to create a simple and useful application for calculating student grades.

## ✨ Features

- Accepts student name as input.
- Accepts marks for multiple subjects.
- Calculates total marks.
- Calculates percentage.
- Determines the final grade automatically.
- Displays a clear and organized result.
- Beginner-friendly Python implementation.

## 🛠️ Technologies Used

- 🐍 Python 3.x
- 💻 Python IDLE
- 🔧 GitHub

## 📚 Python Concepts Used

### Variables

Variables are used to store the student's name and subject marks.

### User Input

The input() function is used to collect information from the user.

### Arithmetic Operations

Addition and percentage calculations are used to calculate the student's performance.

### Conditional Statements

if, elif, and else statements are used to determine the grade based on the percentage.
