## 📌 Overview

Day 19 focuses on building a simple **AI Study Assistant** as part of **Module 5 — AI Tools & Mini Project**.

The application is designed to provide beginner-friendly explanations for common technical topics such as Python, Machine Learning, Supervised Learning, Pandas, NumPy, Cybersecurity, and Phishing.

The project runs locally using Python and does not require an API key or external AI service.

---

## 🎯 Objective

The main objectives of this project were to:

- Build a simple AI-based study assistant.
- Provide educational responses based on user questions.
- Practice Python programming and conditional logic.
- Create an interactive command-line application.
- Improve understanding of AI-assisted learning concepts.

---

## ⚙️ How It Works

The application follows a simple workflow:

```text
User enters a topic
        ↓
User enters a question
        ↓
Program analyzes the input
        ↓
Matching topic is identified
        ↓
Relevant educational response is displayed
```
