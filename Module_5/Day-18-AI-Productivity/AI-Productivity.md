## 📌 Overview

Day 18 is the second practical task of **Module 5 — AI Tools & Mini Project** in the Codomax Digital Solutions Internship.

## 💻 1. AI for Coding

ChatGPT was used to assist with a simple Python programming task.

### Prompt Used

```text
Write a simple Python program that checks whether a number is even or odd.
Explain the code step by step for a beginner.
```
---

### Python Code

```python
number = int(input("Enter a number: "))

if number % 2 == 0:
    print("The number is even.")
else:
    print("The number is odd.")
```

### Example Output

```text
Enter a number: 10
The number is even.
```

### Learning

This activity demonstrated how AI can assist with:

* Code generation.
* Code explanation.
* Understanding programming logic.
* Improving coding productivity.

## 🔎 2. AI for Research & Learning

Google Gemini was used to explore a Machine Learning topic.

### Prompt Used


The generated information was reviewed to improve understanding of the topic.

### Learning

* Organizing research notes.
* Supporting self-learning.

## 🛡️ Responsible Use of AI

AI-generated content should be reviewed before use.

The following workflow was followed:

```text
AI Generated Response
       ↓
Review
       ↓
Understand
       ↓
Verify
       ↓
Edit
       ↓
Final Use
```

AI should be used as a **learning and productivity assistant**, not as a replacement for personal understanding.
